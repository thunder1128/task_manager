# タスク管理WEBアプリ

Python標準ライブラリ + SQLite で動く、軽量なタスク管理アプリ。追加インストール不要。

## 起動方法

```bash
cd task_manager
python3 server.py
```

ブラウザで http://127.0.0.1:8000 を開く。停止は `Ctrl+C`。

## 機能

画面はヘッダーのタブで **かんばん** / **バックログ** を切り替えられる。

### かんばんビュー
- **基本操作**: タスクの追加 / 編集 / 完了 / 削除
- **かんばんボード**: 初期は 未着手 → 進行中 → 完了 の3列。カードをドラッグ&ドロップで列移動(「→ 次の列」ボタンでも可)
- **列(ステータス)の追加・編集・削除・並び替え**: ボード右端の「+ 列を追加」で列を追加。各列ヘッダーの `◀ ▶` で並び替え、`✎` で名前変更、`🗑` で削除できる。
  - 列を「完了扱い」に設定すると、その列のタスクが進捗率・取り消し線に反映される(初期は「完了」列がこれ)
  - 列を削除しても中のタスクは消えず、隣の列へ移動する。最後の1列は削除不可
- **優先度**: 高 / 中 / 低(色付きの左ボーダーとバッジで表示)
- **期限**: 締切日を設定。超過・当日・間近を色分け表示
- **カテゴリ / タグ**: 分類とフィルタリング
- **検索・絞り込み**: タイトル/説明の検索、優先度・カテゴリ・タグ・イテレーションでの絞り込み
- **進捗統計**: 全体件数と完了率をヘッダーに表示

### バックログビュー(イテレーション計画)
- **イテレーション(スプリント)**: 名前・ゴール・期間・状態(計画中/進行中/完了)を設定して作成・編集・削除
- **プロダクトバックログ**: イテレーション未割り当てのタスクをまとめて表示
- **割り当て**: タスクカードをパネル間でドラッグ&ドロップして、バックログ ⇄ 各イテレーションを移動。タスク編集画面の「イテレーション」欄からも指定可
- **並び替え**: パネル内でカードを上下にドラッグして順序を入れ替え。**並び順はサーバー(`position`)に永続化**され、再読み込み後も保持される(かんばんの各列内でも同様に並び替え可)
- **進捗**: 各イテレーションに「完了/総数」を表示
- **安全な削除**: イテレーションを削除しても配下のタスクは消えず、プロダクトバックログへ自動的に戻る

## 構成

| ファイル | 役割 |
|---------|------|
| `server.py` | バックエンド(HTTPサーバー + REST API + SQLite) |
| `index.html` | フロントエンド(単一HTML。UI全部入り) |
| `tasks.db` | データベース(初回起動時に自動生成) |

## API

| メソッド | パス | 内容 |
|---------|------|------|
| GET | `/api/tasks` | タスク一覧 |
| POST | `/api/tasks` | タスク作成 |
| PUT | `/api/tasks/<id>` | タスク更新 |
| DELETE | `/api/tasks/<id>` | タスク削除 |
| POST | `/api/tasks/reorder` | グループ内の並び順を保存(`ids` の順に `position` を更新。任意で移動先 `column_id` / `iteration_id` も同時設定) |
| GET | `/api/columns` | かんばん列一覧 |
| POST | `/api/columns` | 列作成(`name`, 任意 `is_done`) |
| POST | `/api/columns/reorder` | 列の並び順を保存(`ids` の順に `position` を更新) |
| PUT | `/api/columns/<id>` | 列更新(`name` / `is_done`) |
| DELETE | `/api/columns/<id>` | 列削除(配下タスクは隣の列へ退避。最後の1列は不可) |
| GET | `/api/iterations` | イテレーション一覧 |
| POST | `/api/iterations` | イテレーション作成 |
| PUT | `/api/iterations/<id>` | イテレーション更新 |
| DELETE | `/api/iterations/<id>` | イテレーション削除(配下タスクはバックログへ退避) |

タスクは `column_id`(所属するかんばん列)と `iteration_id`(数値=所属イテレーション / `null`=プロダクトバックログ)を持つ。
列は `is_done`(その列を「完了」として扱うか)を持つ。

## 設定変更

`server.py` 冒頭の `HOST` / `PORT` で待受アドレスを変更できる。
